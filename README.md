# F editor (nf), UC Irvine, 1981-84

This commit holds the files exactly as they came off the tape, byte for byte.
The next commit adds what is needed to build and run them today.

- `original/` is `~willson/feditor` from tape6: nf, the F editor in C for
  VAX/Unix by Stephen Willson (October 1981, last changed September 1982), with
  its Makefile, its manual `nf.doc` and the VAX a.out binary `nf`.
- `tadman/ada/original/` is `thesis/ada_f`: Frank Tadman's Ada transliteration
  of nf for the UCI Ada environment (1983-84), as found partway through debugging.
